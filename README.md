# ContenidoAudiovisual

*Programación Orientada a Objetos*

**#Tarea 1: Unidad 2** - Relación entre Clases

Propósito:

Reforzar el dominio de la Programación Orientada a Objetos mediante la expansión e integración de clases, además de gestionar proyectos en GitHub.

Objetivos:

-Integrar nuevas clases al proyecto base (ContenidoAudiovisual) mediante el uso correcto de herencia, asociación, agregación y composición.

-Elaborar un diagrama de clases que represente visualmente la estructura, atributos y las interacciones entre los objetos del proyecto.

-Aplicar flujos de trabajo utilizando GitHub para facilitar la administración y el despliegue del proyecto.
